# Mathematical Perspectives on Machine Learning

**机器学习研究中的数学结构与建模笔记**

这份笔记整理我在无人机射频识别、阵列测角和数字孪生信道重构中积累的数学理解视角。目的在于形成可反复使用的建模习惯：遇到新的任务或失败现象时，先从观测、信息与结构出发，再决定采用什么模型。

核心路径是：**实际现象 → 任务目标 → 可检验的数学结构 → 结构进入模型的方式 → 实验判断**。案例中的假设和说明性数字用于解释机制；训练曲线等经验观察与原因推断分别陈述。

低秩、稀疏、循环平稳、图结构和对称性分别约束不同对象。**贝叶斯学习是结合似然与先验进行推断的框架**，可以利用这些结构；最大后验估计 MAP 是其中一种点估计，完整的贝叶斯推断还涉及后验分布与预测不确定性。

## 使用方式

面对一个高维观测，先明确需要保留什么任务信息，以及现有测量能否辨识目标；再检查合适表示中的**低秩性、稀疏性、统计规律、相似关系与变换对称性**，并确定输出必须满足的约束。将可信结构放入特征计算、观测模型、参数化、正则项或概率先验，结合噪声和部署分布选择推断方法，最后用对照验证任务收益。

阅读时优先选择与当前现象最接近的一两个视角。**结构存在、方法利用了结构、利用结构改善了任务**，是三个需要区分的判断。

## 1、任务信息保留与特征互补

### 1.1 场景与建模目标

在无人机 RF 识别中，对频谱图去噪、压缩或重构后，再将结果送入分类器。两种机型的主要频带和大部分能量都相近，真正区别可能是一个很弱的杂散峰、边带形状或时间统计。重构器优先保住强能量部分后，图看起来几乎没变，分类所需的证据却可能消失。

**建模导向：特征处理以保留目标任务所需的证据为准则；输入重构与类别判别分别评价。**

### 1.2 数学结构

**专业术语：任务风险、任务充分性、条件互信息与信息冗余。**

**理解重点：输入相似度与任务信息不是同一个量。** 假设 99% 的能量来自各类共有的主信号，只有 1% 来自有辨识力的弱结构；丢掉后者可能只带来很小的相对重构误差，却严重损害分类。这里的数字仅用于说明机制。

若 Z_1 是现有特征，Z_2 是补充特征，C 是类别，额外类别信息可用下式理解：

```math
I(C;Z_1,Z_2)=I(C;Z_1)+I(C;Z_2\mid Z_1).
```

**可检验的数学结构：任务充分性与条件信息增益。** 理想的任务充分表示 T(X) 满足 P(C∣X)=P(C∣T(X))，即表示保留了判别类别所需的信息。两个分支是否互补，要看补充特征在给定现有特征后是否仍减少类别不确定性；不要求它们正交。

表面变化很小而预测改变，还可能涉及其他机制：**表示压缩**可能丢掉信息，**对抗样本**可能保留可辨识内容却使现有模型出错，**数据投毒**则修改训练数据以影响学习过程。三者不能直接等同。

### 1.3 解决策略

先固定任务指标和数据划分，比较完整表示、压缩表示和补充时间特征后的表示。若压缩造成类别信息损失，可保留相关频块、加入另一种统计视图，或用监督分类目标学习压缩，而不只优化输入重构。

融合策略也应服务于条件信息增益。参数更多或训练更充分，同样可能造成性能变化，需要控制这些因素。

### 1.4 验证与适用边界

重点比较留出集分类损失、混淆类别和校准情况，再辅助查看重构误差。实际分类器的性能对照是证据，不等于精确测量了真实互信息。

### 1.5 可迁移场景

图像去噪后微小病灶消失、语音压缩后说话人特征变弱、降维后低方差类别证据消失，都可以先问这一问。**归纳：看起来像，不等于保住了任务需要的信息。**

## 2、部分观测与数据选择机制

### 2.1 场景与建模目标

部分时频块未被采集，却在矩阵中被人工填零。模型只看到零值时，不能普遍知道它表示未观测还是实际测到了零。进一步设想一个 RF 数据集：采集程序只保存能量超过检测门限的片段，那么训练数据会系统性漏掉弱信号。后一个问题即使没有任何零填充，也属于观测机制问题。

**建模导向：输入同时表达测量值与观测状态，建模时进一步考虑数据进入样本集的机制。**

### 2.2 数学结构

**专业术语：观测掩码、部分观测、缺失机制与选择偏差。**

令 M 的条目表示是否观测，简单记录可写为：

```math
X_{\mathrm{obs}}=M\odot X,\qquad M_{ijk}\in\{0,1\}.
```

**第一层是编码问题：**用掩码区分“没有数值”与“数值为零”。掩码表达观测状态，但不能自动恢复缺测内容。

**第二层是统计问题：缺失概率可能依赖信号内容。**若每个位置独立随机丢包，与信号内容无关，可以先研究随机缺失；若接收机在能量低于门限时不保存样本，缺失就依赖信号自身，观测到的数据更偏向强信号。若记录了“低于门限”这个事实，还可利用删失信息，而非把它当成完全无信息。

**结构判断：观测了什么，本身就是统计问题的一部分。**

### 2.3 解决策略

将数据与掩码一起保存，输入模型时提供掩码，或对缺测部分采用明确的处理规则。若任务是重构，数据拟合项可以只在实际观测的位置计算；推断未观测值则还需要低秩、平滑或其他可信结构。

门限检测时，记录门限与触发规则，必要时建模“被观测的概率”或“低于门限的事件”。具体结构可以进入选择模型 p(M∣X)、观测似然或采集方案。[缺失机制与建模](https://sites.stat.columbia.edu/gelman/arm/missing.pdf)

注意：只有在选择概率可估计、需要推断的区域具有足够覆盖等条件下，重加权才可能纠正部分偏差；掩码本身不消除选择偏差。

### 2.4 验证与适用边界

在完整样本上人为施加已知掩码，比较填零、显式掩码与其他处理；再检查实际丢包模式是否与人工设定一致。完全缺失且没有可迁移规律的内容，不能靠填补恢复真值。

### 2.5 可迁移场景

只对成功解码的数据训练、只保存清晰图像、只统计已点击商品，都要问“没进入数据集的样本有什么共同特征”。**归纳：补零是入口，真正要追问的是谁被观测到了，以及为什么。**

## 3、可辨识性与观测等价类

### 3.1 场景与建模目标

以数字孪生辅助信道重构为背景，考虑只使用功率角度谱 PAS、功率时延谱 PDP 预测完整复信道 H 的简化设定。功率特征吻合，复数 NMSE 仍可能较大；这是观测信息与估计目标不匹配的一个例子。

**建模导向：先判断观测是否能够区分目标，再决定补充测量、引入先验或改变估计对象。**

### 3.2 数学结构

**专业术语：可辨识性、观测等价类、欠定逆问题与后验不确定性。**

对任意共同相位 phi，令：

```math
H'=e^{j\phi}H.
```

当 PAS、PDP 由线性变换后的模平方及其聚合构成时，共同相位不改变它们。若直接把 H′ 当预测、H 当标签，标准复数 NMSE 为：

```math
\frac{\|e^{j\phi}H-H\|_F^2}{\|H\|_F^2}
=|e^{j\phi}-1|^2=2-2\cos\phi,\qquad H\ne0.
```

例如相位相反时该值为 4，而功率观测仍相同。PAS、PDP 若是二维功率分布的两个边缘分布，还可能丢失角度与时延怎样配对的信息；固定共同相位也不保证所有歧义消失。

**因此，仅从这些功率观测出发，一般不能唯一确定原始复信道。** 这给出了一个具体的不可辨识性反例。

### 3.3 解决策略

若任务必须恢复带绝对相位参考的 H，需要增加相位参考、允许的复数测量或其他能够消除歧义的信息。若实际任务只需要功率或某个等价类，应按该目标定义输出和损失；评价定义的改变必须符合任务要求。

**对应策略还包括区分“由观测确定”与“靠先验选解”。** 贝叶斯方法可以用先验偏好某些相容信道，并表达后验不确定性；它不能凭空制造测量里没有的证据。若相位在给定输入后仍完全随机，更多同类功率训练样本也不能普遍恢复每次真实相位。

### 3.4 验证与适用边界

先直接构造多个产生相同功率观测的复信道，检查任务是否仍要求区分它们。增加独立相位参考后，再看歧义是否减少。

**输入信息缺失与训练样本不足需要分开。** 在此观测模型下，增加同类功率训练样本不能普遍消除相位歧义；参数学习不足则可能随数据增加而改善。后验变窄本身不保证模型正确或已校准。

### 3.5 可迁移场景

单张图像的绝对深度、只看投影恢复三维形状、欠定线性方程，都会遇到“多个真实对象产生同一观测”。**归纳：先问答案是否能由这些输入区分，再问网络能不能学出来。**

## 4、字典表示与结构化稀疏

### 4.1 场景与建模目标

以少数来波方向的阵列测角为例：各阵元的接收波形都不为零，但在选定角度范围与分辨率下，可能只有少量有效角度占据主要贡献。稀疏的对象是角域系数，而不是阵元编号对应的原始观测。丰富散射环境不一定满足这个假设。

**建模导向：在具有物理或统计意义的字典中定位少数活跃成分，并明确条目、组与跨快拍支持结构。**

### 4.2 数学结构

**专业术语：过完备字典、联合稀疏、组稀疏正则、收缩估计与自动相关性确定 ARD。**

在多个快拍共享方向的假设下：

```math
Y=AS+N.
```

A 的列对应候选方向，S 的行对应各方向在多个快拍中的系数。原始 Y 可以很密集，S 却只有少数行活跃。

**可检验的数学结构：在物理字典中，仅少数行或少数组活跃。** “空域一般稀疏”应收紧为“在少数有效路径假设下，角域可能近似稀疏”。若有扩展散射簇，可能是块稀疏或近似稀疏；若角度持续扩展，则少数点源模型会失配。

### 4.3 解决策略

先根据阵列物理构造字典，再研究行稀疏系数。例如可使用组稀疏正则：

```math
\widehat S=\arg\min_S
\|Y-AS\|_F^2+\lambda\sum_g\|S_{g,:}\|_2.
```

**正则化的含义：在解释数据的同时，对允许的解施加额外偏好。** 仅最小化观测误差可能产生很多解，甚至拟合噪声；正则项在这些解之间偏好特定结构。λ 控制数据吻合与结构偏好的权衡。

上式第一项解释观测，第二项先对每一行求二范数，再对各行求和，鼓励整行一起收缩为零。它表达“少数方向在这个短时间窗内跨快拍共同活跃”，并不要求这些方向每个快拍的幅度相同。普通二范数平方通常使系数普遍变小；一范数或组范数更可能使部分系数或组精确变成零。

**贝叶斯对应：**在适当噪声与尺度设定下，MAP 目标可以写成：

```math
\widehat S_{\mathrm{MAP}}
=\arg\min_S\{-\log p(Y\mid S)-\log p(S)\}.
```

因此，正则项可对应负对数先验。例如 p(S) 与 exp(−c∑_g‖S_g,:‖₂) 成正比时，MAP 中出现组范数惩罚。固定方差的零均值高斯先验对应二范数平方收缩，**通常不会给出稀疏解**。

**SBL 的高斯用法不同：**给每个方向一组可学习的方差，例如条件独立快拍下：

```math
p(S\mid\gamma)=\prod_g\prod_t
\mathcal{CN}(s_{gt};0,\gamma_g),\qquad\gamma_g\ge0.
```

同一方向共享 γ_g，许多 γ_g 被学习到接近零，该方向整行随之被强烈压缩。常见 SBL 用边缘似然学习这些超参数，再计算系数后验；这不等于把所有参数一次做普通 MAP，也不是给整批样本拟合 GMM。[SBL 原始论文](https://www.jmlr.org/papers/v1/tipping01a.html)

**稀疏恢复与高斯混合的建模对象不同。** GMM 用若干高斯密度的加权和描述样本分布；稀疏恢复用观测方程 Y=AS+N 推断哪些系数活跃。若将一条非负角度功率曲线拟合为少数高斯峰，可以称为高斯基函数拟合；规范化并明确随机变量后，也可研究密度模型。但峰数少、系数稀疏和 GMM 分量数少，是三个不同的约束。**高斯函数能拟合形状，不自动提供少数方向恢复、跨快拍共享支持或物理一致性的保证。**

高斯混合也可以被专门用于设计系数先验，例如用窄方差与宽方差分量分别表达“接近零”与“显著活跃”。但必须明确随机变量是待恢复系数，并将该先验与观测方程联合起来；这与直接对观测样本拟合一个普通 GMM 是不同的建模步骤。

### 4.4 验证与适用边界

用已知方向的模拟或标定数据，扫描角度间隔、源数和噪声，评价分辨率与虚假方向。检查离栅格误差、阵列失配和字典列相似性。

换域可能使系数集中，但对同一矩阵作两侧可逆线性变换不改变矩阵秩。**更稀疏与更低秩是不同判断。**

### 4.5 可迁移场景

少数时延路径、少数故障传感器、少数活跃频率，都可先构造“候选成分 → 观测”的模型，再问哪些组应活跃。**归纳：稀疏恢复在选成分，GMM 在解释样本来自哪个分布分量。**

## 5、低秩近似与多维因子

### 5.1 场景与建模目标

大矩阵如果可以由少量基与系数近似表达，神经网络便有机会在较低维的空间中学习。具体实现首先区分：**所有样本共享一组基**，还是**每个样本各有自己的低秩子空间**。前者可只预测系数，后者通常还要估计随样本变化的基。

**建模导向：以较少自由度表达主要变化，区分共享基学习、低维系数预测与随样本变化的因子估计。**

### 5.2 数学结构

**专业术语：低秩近似、多线性结构、张量分解与可分离因子。**

先看矩阵情形。设训练数据按列组成 X，SVD 为 UΣVᴴ。若前 10 个奇异值的平方和占总和的 98%，则相应截断近似保留 98% 的平方 Frobenius 能量：

```math
\eta_{10}=\frac{\sum_{i=1}^{10}\sigma_i^2}
{\sum_i\sigma_i^2}=0.98,\qquad
\frac{\|X-X_{10}\|_F^2}{\|X\|_F^2}=0.02.
```

相对 Frobenius 范数误差为 √0.02，约 14.1%，所以“保留 98% 能量”不等于“每个元素误差只有 2%”，也不等于保住 98% 的类别信息。这是**近似低秩**，未必是精确秩等于 10。

再看“阵元 × 子载波 × 时间”的信道张量：若短窗内只有少数主要路径，路径方向、时延近似不变，增益随时间变化，可以提出：

```math
H[m,f,t]\approx
\sum_{k=1}^{K}a_k[m]\,b_k[f]\,c_k[t].
```

上式是 CP 型可分离因子模型。**SVD 是矩阵分解；PCA 是寻找主方差方向的统计方法，通常对中心化数据用 SVD 或协方差特征分解实现；Tucker 分解用各轴的因子矩阵与核心张量表示多维数据。** 它们相关，但不是三个可以完全互换的名字。

**低秩强调有效自由度少，多维因子结构进一步说明这些自由度怎样沿不同轴组合。** 矩阵秩、CP 秩和 Tucker 多线性秩不是同一概念。[张量分解综述](https://www.kolda.net/publication/koba09/)

### 5.3 解决策略

**对应策略一：固定共享基，只学系数。** 仅用训练数据估计 B_r，再让网络根据位置、环境或部分观测预测 r 维系数：

```math
\widehat x=\mu+B_r f_\theta(q).
```

这里 q 是用于预测的输入，μ 是训练数据均值。网络主要学习“这个样本在基上的坐标”，而非每次重新学习基。

**对应策略二：基随样本变化，学习因子或局部基。** 例如预测 U_r、Σ_r、V_r 后重构矩阵，或对不同传播区域使用不同子空间。若要联合学习共享基与系数，可使用低维解码器，但必须控制尺度、排列等不唯一性。

物理条件充分时，还可约束空间因子为阵列响应、频率因子为时延响应；否则只能先将它们理解为统计因子。

### 5.4 验证与适用边界

**怎样检验：**先画训练数据奇异值谱，再检验留出位置和新条件下的子空间投影误差。98% 这一阈值只对计算它的那批数据及度量成立；新场景可能出现原子空间没有的方向。还要评价下游分类或测角，因为低能量成分可能很有用。

若路径参数在窗内快速变化，可分离模型可能失配。分解还可能存在尺度、排列或更深的非唯一性，不能直接把每个因子认定为真实路径。

### 5.5 可迁移场景

图像背景压缩、多传感器共有模式、信道角度与时延因子，都可问“少量坐标能否解释主要变化”。**归纳：共享基已知时学坐标，子空间也变化时还要学基。**



MUSIC 提供了另一种低秩结构：在少数有效源与白噪声假设下，**信号协方差项**可能低秩，而含噪的总协方差通常是满秩的。

```math
R_x=A R_s A^H+\sigma^2 I.
```

这使信号子空间与噪声子空间的分解成为候选思路；有效性仍取决于源相关性、快拍数、阵列模型和特征值分离。[MUSIC 原始论文](https://codar.com/images/about/1986Schmidt_MUSIC.pdf)

## 6、二阶统计量与循环平稳性

### 6.1 场景与建模目标

无人机 RF 特征提取中的一项候选结构是：不同截取片段的波形并不相同，但某些谱形在选定条件下较稳定，时域中的二阶统计可能具有循环平稳性。这个判断应当写成可验证的统计假设，而不是要求网络把每个随机波形都记住。

**建模导向：从随机波形中提取可重复估计、对目标有辨识力的统计规律。**

### 6.2 数学结构

**专业术语：二阶统计量、局部谱稳定性、循环平稳性与统计特征提取。**

均值、自相关、协方差和功率谱属于不同层次的统计描述。自相关涉及两个时刻信号的乘积，属于二阶统计。二阶循环平稳要求均值与相关函数满足相应周期条件；以零均值过程为例，相关周期可写为：

```math
R_x[n,\ell]=\mathbb E\{x[n]x^*[n-\ell]\},
\qquad R_x[n+P,\ell]=R_x[n,\ell].
```

这约束的是统计量。非零循环频率上的相关分量可以揭示普通平均谱未完整保留的周期统计信息。[循环平稳与谱相关理论](https://faculty.engineering.ucdavis.edu/gardner/wp-content/uploads/sites/146/2013/02/The_Spectral_Correlation_Theory_of_Cyclostationary_Time-Series.pdf)

**可检验的数学结构：统计量对绝对时间的周期依赖。** “频域平稳”在这里更准确地表达为“选定窗口和条件下，平均谱形或谱占用具有稳定性”，不能仅据此断言把频率当索引后是一个平稳随机过程。波形周期、局部谱稳定与循环平稳也不是同一命题。

### 6.3 解决策略

**对应策略：**按协议与采样率选择观察窗、候选时延和循环频率，估计平均谱、自相关或循环谱，再看哪些量跨片段稳定且能区分类别。循环前缀、符号时钟等通信机制可以为候选周期提供线索，是否能在实际接收条件下稳定观测还需验证。若统计特征估计可靠，再把相关计算、局部平均或可学习组合放入网络。

将结构写进特征计算，是一种归纳偏置；不必先将它改写成参数先验。注意力也可作为学习相关关系的候选机制，但使用注意力不等于严格计算了循环谱。

### 6.4 验证与适用边界

检查统计规律是否跨录制、观察窗和同步偏差保持，并验证其对类别是否有额外帮助。平均谱与普通自相关在理想宽平稳二阶模型下是傅里叶对应描述，不能仅因分支不同就断言互补。

统计规律存在、估计器能稳定估计、特征能改善任务，是三个检验步骤。

### 6.5 可迁移场景

机械振动的周期冲击、心电的节律、通信帧的重复统计，都可以从“统计规律重复”入手。平均可能降低估计波动，也可能抹去短暂事件；应按任务选取。**归纳：随机的是样本，可能稳定的是产生样本的统计规律。**

## 7、任务相关相似度与图结构

### 7.1 场景与建模目标

在数字孪生信道重构的近邻参考策略中，某个参考点离目标很近，却隔着墙；另一个点更远，但共享候选反射面或连通区域。若只按距离平均，把二者当作同等可信的参考，可能把不同传播机制混在一起。

**建模导向：依据任务中的真实连接关系共享信息，并允许传播边界或工况边界处发生突变。**

### 7.2 数学结构

**专业术语：任务相关相似度、图结构、局部回归与分段平滑性。**

**可检验的数学结构：传播关系图上的局部可迁移性与分段平滑性。** 平滑对象可以是对齐后的功率谱、等效路径参数或其他任务表征；图边表示具有共享传播信息的关系。遮挡边界处允许突变，而非要求整个空间处处平滑。

**局部平滑必须说明沿什么关系平滑。** 矩阵索引相邻、物理距离近与传播相似，不一定是一回事。

### 7.3 解决策略

**对应策略：**一种实现是先按距离筛选参考点，再根据遮挡、候选反射面和地图连通分量等拓扑关系排序，对等效路径做迁移与几何校正。关键不是直接把整幅复信道谱平均起来，而是先判断哪些传播信息可迁移、怎样迁移。这样的权重是建模选择，不能仅因形式像概率就称为后验概率。

若将这一思想推广成图平滑，令 W_ij 表示样本 i、j 应共享信息的强度，可使用如下结构惩罚：

```math
\mathcal R(F)=\frac12\sum_{i,j}W_{ij}\|f_i-f_j\|_2^2.
```

它鼓励强连接节点的表示接近。**邻居检索、局部回归与图消息传递是不同实现选择**；多跳传递还会沿路径累积错误，图连通不表示任何信息都可以无限传播。

该策略也适用于传感器网络、点云和其他关系数据；相似度与边的物理含义需要重新定义。

### 7.4 验证与适用边界

比较仅距离、任务相关权重和不使用邻居的基线，分别评价区域内部和边界。检索库只能包含预测时允许访问的参考样本。

若借用复信道，还需处理快速相位变化，不能把功率特征的局部平滑直接推广到复数元素。

### 7.5 可迁移场景

同类传播区的信道迁移、同工况设备之间借数据、关系网络中的信息共享，都要先定义有效的边。**归纳：近不一定像，先判断共享什么，再决定如何融合。**

## 8、变换不变性与等变性

### 8.1 场景与建模目标

从连续数据流中随机截取样本时，需要区分位置变化与内容缺失。先考虑完整内容保留的情形：同一个完整信号只是在窗口中的位置发生平移。机型标签应保持，发射事件的开始时间应跟着移动。但真实的随机截窗还可能截掉关键片段，因此不一定只是平移。

**建模导向：按任务明确输入变换对应的输出规则，将应忽略的变化与应保留的变化分别建模。**

### 8.2 数学结构

**专业术语：变换作用、不变性、等变性与参数共享。**

设 T_delta 表示时间平移，g 输出类别，d 输出起始时刻，则期望关系可以是：

```math
g(T_\delta X)=g(X),
\qquad
d(T_\delta X)=d(X)+\delta.
```

类别对该变换不变，时间输出则应跟随变换。**该忽略的变化与该保留的变化，由任务决定。**

### 8.3 解决策略

**对应策略：**若增强只改变位置且完整保留判别内容，分类标签保持不变，时间定位标签同步平移。分类网络可通过参数共享、合适的池化或对齐减少对绝对位置的依赖；定位网络则要保留坐标。若随机截窗可能只剩噪声或截掉协议标志，必须调整采样规则、提供有效区间或重新判断标签是否仍可识别。

共享局部规则的卷积可提供平移等变的建模思路，但整个网络是否严格等变，还受边界、步幅、池化等影响。将所有位置都压成一个向量，可能损害定位。[卷积与等变性](https://www.deeplearningbook.org/contents/convnets.html)

### 8.4 验证与适用边界

对同一留出样本施加不同平移，同时检查类别变化与时间输出偏差。如果平移造成裁剪、截断或丢失事件，则已不是本例假设的完整内容变换。

这与第 6 节不同：第 6 节研究数据内部的统计规律，本节规定输入变化时模型输出应遵守的关系。

### 8.5 可迁移场景

图像中目标平移后类别不变而框的位置要变；阵列几何旋转后角度输出要按规则变。**归纳：完整内容变位置与内容被截断，是两种问题；不变或等变都要先说明允许什么变换。**

## 9、输出约束与矩阵流形

### 9.1 场景与建模目标

在需要预测矩阵分解中的基或保范数变换时，神经网络的输出可能被要求为酉矩阵 U。自由预测矩阵元素再惩罚 UᴴU 与 I 的差异，只是在损失中鼓励满足约束；利用李代数和矩阵指数，可以在结构上保证酉性。协方差预测则对应另一种可行集合。

**建模导向：通过输出参数化保证数学合法性，再在可行集合内优化任务性能。**

### 9.2 数学结构

**专业术语：酉群 U(n)、李代数、反厄米矩阵、指数映射与约束参数化。** 酉矩阵满足 UᴴU=I，表示保范数的复数线性变换；实数对应物是正交矩阵。

让网络先预测任意复矩阵 B，再构造反厄米矩阵 K：

```math
K=\frac{B-B^H}{2},\qquad K^H=-K,\qquad U=\exp(K).
```

因为 K 与 −K 可交换，有：

```math
U^HU=\exp(K^H)\exp(K)=\exp(-K)\exp(K)=I.
```

这里 exp 是**矩阵指数**，不是对每个元素分别取指数。

**厄米与反厄米参数化需要保持一致。** 若 A=B+Bᴴ，则 A 是厄米矩阵，应使用 exp(iA)；若 K=B−Bᴴ，则 K 是反厄米矩阵，应使用 exp(K)。两条路线都能生成酉矩阵，但不可混淆其条件。

### 9.3 解决策略

**对应策略：把数学约束编码进输出映射。** 可以采用上面的反厄米路线，也可以改用 A=(B+Bᴴ)/2，再输出 exp(iA)。网络仍可以在 B 的普通参数空间中优化；矩阵指数使输出保持在酉群上。[李群参数化与酉约束](https://proceedings.mlr.press/v97/lezcano-casado19a.html)

若输出目标换成协方差矩阵，约束也随之改变：协方差要求厄米半正定，不能直接用“酉矩阵”代替。一种相应构造是：

```math
\widehat R=LL^H+\epsilon I,\qquad\epsilon>0.
```

这样保证正定；epsilon 的选择也会引入限制或偏差。若只要求半正定，可考虑相应参数化或将结果投影到半正定集合。

**结构放在输出参数化或约束算子中。** 相比仅在损失里惩罚非法矩阵，这类构造可以直接保证所规定的条件。

### 9.4 验证与适用边界

**怎样检验：**报告 ‖UᴴU−I‖_F、原任务误差，以及矩阵指数带来的计算开销。在精确算术下公式保证酉性，实际实现应检查复数构造和浮点误差。若输出协方差，则检查半正定性、估计误差与下游测角性能。

若 U 用于 SVD 或特征分解，还要注意：**基向量的相位、符号和排列可能不唯一，重特征值子空间内的基还可旋转。** 直接拿预测基与标签基逐元素做 MSE，可能惩罚数学上等价的答案；可根据任务比较重构矩阵、子空间投影或采用合适的对齐。合法性与正确性仍须分别验证。

### 9.5 可迁移场景

非负功率、归一化概率、半正定协方差、旋转或酉变换，都可以先找“任意网络输出 → 合法对象”的映射。**归纳：让数学负责合法性，让网络学习合法空间里哪个答案更好。**

## 10、误差模型与训练稳定性

### 10.1 场景与建模目标

在无人机 RF 频谱图分类实验中，曾观察到 ResNet 的准确率与 loss 大幅震荡，而最佳模型仍有一定识别效果。一项候选解释是连续数据流中的片段、工况和批次组成存在明显差异；另一项候选解释是表示没有有效利用稳定统计结构。**训练曲线记录了现象，尚不能单独确定原因。**

**建模导向：区分误差分布、批次统计和参数更新，利用对照定位训练波动的来源。**

### 10.2 数学结构

**专业术语：残差分布、稳健估计、随机梯度方差、批次异质性与优化稳定性。** 这里的“预测残差”是预测减观测或标签，不是 ResNet 中的残差连接。

**先区分回归与分类。** 若拟合接收功率并使用平方损失，残差从 1 增至 10，损失贡献从 1 增至 100；少量大偏差样本可能主导目标和更新。这时可以检查重尾或异常污染，并研究 Huber 损失：

```math
\rho_\delta(r)=
\begin{cases}
\frac12r^2,&|r|\le\delta,\\
\delta(|r|-\frac12\delta),&|r|>\delta.
\end{cases}
```

Huber 在小残差处保持平方形状，大残差处变成线性增长。对于采用 softmax 交叉熵的分类模型，目标是：

```math
\ell=-\log p_\theta(C=y\mid X),\qquad
\frac{\partial\ell}{\partial a_c}=p_c-\mathbf 1\{c=y\},
```

其中 a_c 是类别 logit。真实类别概率很小时，loss 可以很大；但对 logit 的上述梯度分量有界，**不能据此直接断言发生了梯度爆炸，更不能把原因直接归于平方残差**。

### 10.3 解决策略

**对应策略：用几个有区分力的对照诊断。**

| **待检验的原因** | **具体检查** | **什么观察支持它** |
| --- | --- | --- |
| 记录口径造成视觉上的抖动 | 区分单 batch、整 epoch 与固定完整验证集；按样本数正确平均 | 单 batch 很抖，但完整验证指标较稳定 |
| 学习率或更新幅度过大 | 保持数据和模型不变，降低学习率，并记录梯度与更新范数 | 大幅跳变减弱，同时验证指标没有恶化 |
| batch 的类别、SNR 或录制来源差异大 | 记录每个 batch 的来源；仅在训练集内混合或分层采样 | 波动与特定工况、类别比例或录制块对应 |
| 时序相关性降低有效样本量 | 对照连续取批与按完整录制划分后在训练集内打乱取批 | 批次组成更均衡后梯度波动减少 |
| 少量坏样本、错标签或极难样本 | 查看逐样本 loss、原图和标签，不直接删除 | loss 尖峰集中于可复核的问题样本或工况 |
| 归一化、BatchNorm 或验证流程 | 检查输入尺度、批统计、train/eval 模式与验证样本是否固定 | 修正流程或尺度后波动发生系统变化 |
| 表示没有利用稳定结构 | 在同一划分和训练设置下比较原频谱、可靠统计特征及融合 | 跨录制表现改善，且类别证据得以保留 |

不同对照分别检验不同机制，不能凭同一条震荡曲线同时确认所有解释。[随机梯度与优化](https://www.deeplearningbook.org/contents/optimization.html)

**批次梯度方差的分解。** 取某一参数方向上的单样本梯度 g_i，批均值的方差为：

```math
\operatorname{Var}\!\left(\frac1b\sum_{i=1}^{b}g_i\right)
=\frac1{b^2}\left[
\sum_i\operatorname{Var}(g_i)+
\sum_{i\ne j}\operatorname{Cov}(g_i,g_j)\right].
```

独立同分布、同方差时可简化为 σ_g²/b；连续片段的梯度相关、批次间工况变化都会影响这个结论。**输入像素方差、随机过程平稳性和梯度方差是不同对象**，需要分别测量。

### 10.4 验证与适用边界

**怎样检验：**先固定一批完整验证样本，保存各 epoch 的预测；再冻结同一个模型重复评估，确认评估流程本身是否稳定。随后每次只改变一个诊断因素。整 epoch 与整验证集仍剧烈变化时，才进一步调查更新和数据条件；不能用曲线平滑画法代替真实改进。

将频谱做平均、对齐或归一化可能减少无关变化，也可能抹掉第 1 节中的弱指纹或第 6 节中的周期信息。换成稳健损失更适合有相应误差依据的任务，**不能把分类交叉熵直接换成 Huber 当作通用修复**。最佳一次结果不错，也不能代替独立录制测试与多次运行的稳定性检查。

### 10.5 可迁移场景

回归的大误差、分类的高置信错误、时序训练的批次漂移，都可先问“谁贡献了损失和梯度”。**归纳：曲线震荡是现象，损失、采样和更新是需要分开验证的原因。**

## 11、混合分布与隐藏状态演化

### 11.1 场景与建模目标

以同一无人机的连续 RF 片段为例，假设提取“占空比、带宽、平均功率”等特征后，样本形成两个统计群体：有些片段发送稀疏，有些发送密集。输入中记录了这些特征，却没有逐窗的工作状态标签。这是引入潜变量的一种动机；能否把两个群体解释为真实工作状态，还要通过控制实验核对。

**建模导向：先描述样本来自哪个统计分量，再依据数据是否具有可靠时序引入状态转移。**

### 11.2 数学结构

**专业术语：离散潜变量、混合分布、马尔可夫转移与隐马尔可夫模型。**

**GMM 用离散潜变量表示分量身份。** 记观测特征为 z，潜变量 u∈{1,…,K} 表示“本次样本由哪个高斯分量生成”。建模时先选 u，再从该分量的分布生成 z：

```math
p(u=k)=\pi_k,\qquad
p(z\mid u=k)=\mathcal N(z;\mu_k,\Sigma_k),\qquad
p(z)=\sum_{k=1}^{K}\pi_k\mathcal N(z;\mu_k,\Sigma_k).
```

例如某个片段的占空比被测为 0.7，这是观测；它属于哪个统计状态没有被记录，这个分量身份就是潜变量。训练数据只有 z，没有 u 的观测值，因此 u 是隐藏的。μ、Σ、π 是共享模型参数；**分量身份 u 与这些参数不是同一个对象**。在前述例子中，分量可能对应不同负载，但也可能反映接收距离、SNR 等其他因素。

**从密度估计到软归属：**GMM 首先给出 p(z)，即特征分布的模型；给定一个样本，还能计算：

```math
p(u=k\mid z)=
\frac{\pi_k\mathcal N(z;\mu_k,\Sigma_k)}
{\sum_r\pi_r\mathcal N(z;\mu_r,\Sigma_r)}.
```

这是对“来自哪个分量”的后验判断。EM 在 E 步计算这类软归属，在 M 步更新参数。**分量身份没被观测，不等于它一定是现实中某个已命名的物理状态。**[GMM 与 EM 讲义](https://cs229.stanford.edu/summer2022/cs229-notes7b.pdf)

**再加入时间关系：**如果假定当前状态总结了预测下一状态所需的过去信息，一阶马尔可夫假设写为 p(u_t∣u_1,…,u_{t−1})=p(u_t∣u_{t−1})。配合状态到特征的发射分布，得到 HMM：

```math
p(u_{1:T},z_{1:T})
=p(u_1)\prod_{t=2}^{T}p(u_t\mid u_{t-1})
\prod_{t=1}^{T}p(z_t\mid u_t).
```

这里 u_t 是每窗未直接观测的状态，z_t 是测到的特征。**GMM 描述分量怎样产生样本；HMM 还描述前后状态怎样连接。** 一般的 HMM 不要求发射分布一定是高斯，也不是所有“现在与将来有关系”的问题都适合一阶马尔可夫假设。

### 11.3 解决策略

**对应策略：**先检查特征分布是否存在值得建模的多峰，用 GMM 作为密度与软分量归属基线；若保留了连续录制顺序，并且状态有持续性，再加入转移矩阵。比如“当前稀疏发送时下一窗仍稀疏的概率较大”是一项可估计假设，不能先把持续性写死再称为发现。在线只使用当前及过去数据时采用滤波；整段序列已知时可用前向后向推断或 Viterbi 求不同类型的结果。

GMM 主要回答当前样本可能来自哪个分量；HMM 将时间关系加入推断。隐状态后验与对全部模型参数做全贝叶斯推断，也不是一回事。[HMM 课程讲义](https://cs229.stanford.edu/section/cs229-hmm.pdf)

### 11.4 验证与适用边界

**怎样检验：**用可控的发送负载、距离和 SNR 对照，观察分量究竟随哪个因素变化；有真实状态记录时评价识别、切换时间与延迟，没有状态标签时检查留出密度或序列似然。以密度作未知信号拒识还需单独校准阈值，并测已知类误拒和未知类检出，低密度并不自动等于未知类别。

时间模型可能把真实快速切换过度平滑。一阶转移、持续时间和条件独立假设不合适时，应调整模型；没有可靠时间顺序时，静态模型可能更适当。

### 11.5 可迁移场景

一张图片属于哪个未标注场景、一次观测处于哪种设备工况，可用潜变量组织解释；连续工况的持续和切换再引出动态模型。多个源同时叠加则应先写线性或非线性混合观测，不能自动用 GMM 代替。**归纳：GMM 的“隐藏”是分量身份没记录；HMM 进一步把隐藏身份连成时间链。**

## 12、分布偏移与可迁移先验

### 12.1 场景与建模目标

RF 识别首先需要明确目标标签：**发射机个体识别中，发射端硬件的不完美本身就可能是射频指纹的来源；接收机、信道、场地等引入的变化则通常是要抵抗的干扰因素。** 若目标是机型识别，过度依赖训练中那几个设备个体的特性，也可能导致换一台同机型设备就失败。因此不能笼统把“指纹”与“硬件缺陷”分成好特征和坏特征。[硬件指纹与信道影响](https://arxiv.org/abs/1904.07623)

**建模导向：明确目标标签及部署条件，将可迁移的任务证据与随域改变的因素区分开。**

### 12.2 数学结构

**专业术语：域偏移、虚假相关、域适配、域泛化、迁移学习与先验信息。**

可以用一个示意性的生成关系组织思考：

```math
X=F(C,D_{\mathrm{tx}},D_{\mathrm{rx}},E,S)+N.
```

C 表示目标类别，D_tx、D_rx 分别表示发射与接收硬件，E 表示传播环境，S 表示发送内容或状态；它们不必相互独立。要判断的不是抽象的“哪个特征更纯”，而是**哪些因素对当前标签有意义，且在部署条件下仍可用**。

**泛化与适配需要区分。** 迁移学习是更广义的知识复用；同一任务在目标域有数据时，可以研究域适配；训练时没有目标域数据、希望直接适应未见域时，通常研究域泛化。A 上训练后在 B 微调可能减少标注和训练需求，也可能出现负迁移，不能自动保证适配更快或更好。

### 12.3 解决策略

**对应策略：**机型识别应覆盖每类多个设备个体，个体指纹识别则应让同一发射机跨场地、接收机和日期出现。按完整录制分组，并根据部署目标留出设备、场地或接收机。先用交叉采集打破标签与环境的绑定，再比较任务相关归一化、可信增强、共享表示或目标域适配；任何处理都要检查是否同时去掉了有用指纹。

若同分布独立留出也差，优先检查模型容量、正则化、数据质量与模型选择；若主要跨域失败，再分析改变的是哪些因素。目标域使用多少标签、是否见过其无标签数据，都应固定并报告。

### 12.4 验证与适用边界

**单目深度估计说明先验可以帮助推断，也体现了可辨识性的边界。** 单张无额外尺度信息的图像，通常不能唯一确定绝对距离：大小与距离不同的物体可能产生相同成像。学习到的物体尺寸、地面、透视等先验能帮助估计深度；已知相机高度、额外测量或视频运动则可能增加信息。**能在某类场景估计得好，不等于单张图像对所有场景都包含唯一绝对尺度。**[单目深度与尺度歧义](https://papers.nips.cc/paper_files/paper/2014/hash/91c56ce4a249fae5419b90cba831e303-Abstract.html)

避障也未必要求先得到完整地图或精确绝对距离；系统可以利用局部结构、相对深度及接近趋势行动。已有知识可以减少新场景的学习负担，其可迁移性仍应在新条件下检验。用贝叶斯语言描述时，先验与当前观测共同形成后验；观测有歧义时，输出仍可能主要受先验影响，遇到不符合经验的场景就会失效。

### 12.5 可迁移场景

换相机的视觉识别、换工况的设备诊断、跨医院预测、跨接收机 RF 识别，都需要区分标签证据和随域变化的因素。**归纳：先定义该识别谁，再判断什么变化应该忽略；先验帮助选解，也需要接受新场景检验。**

## 建模记录模板

积累新案例时，沿用以下五项即可：

| **记录项** | **应写清楚的内容** |
| --- | --- |
| **场景与建模目标** | 观测是什么，标签是什么，失败发生在什么条件，最终优化什么指标 |
| **数学结构** | 结构约束哪个对象，依赖哪些假设，用一个关系式表达其含义 |
| **解决策略** | 结构进入特征、观测算子、模型参数化、损失约束或概率先验的具体位置 |
| **验证与适用边界** | 与什么基线比较，怎样控制变量，什么结果会推翻解释 |
| **可迁移场景** | 哪些其他任务共享同一结构，迁移时哪些假设需要重新检查 |

有效的积累不止于记录方法名称，还要保留**选择它的依据、它利用的信息，以及它可能失败的条件**。
